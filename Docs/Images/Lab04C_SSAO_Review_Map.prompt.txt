"背景或无效：continue"
"ValidSampleCount++"

5. "判断遮蔽并加权"
"Zs < Zq - Bias ?"
"是：w = 1 - smoothstep(0, Radius, length(S-P))"
"OcclusionSum += w"
"否：本样本贡献 0"
"距离达到 Radius 时，w = 0"

6. "完整循环后归一化"
"AO = saturate(1 - OcclusionSum / SampleCount)"
"有效比例 = ValidSampleCount / SampleCount"

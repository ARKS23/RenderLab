Accuracy constraints:
This is Raster + Global Pixel Shader at an after-Tonemap View Extension callback. It is not compute, temporal filtering, physically linear HDR filtering, or AO. The kernel is a fixed five-tap normalized binomial Gaussian approximation. It blurs RGB and preserves center alpha per direction; Composite preserves ORIGINAL alpha. Only the final composite targets the renderer's OverrideOutput when valid. Zero mix still executes all three passes in this learning implementation, disabled means no blur callback.
